# 🔐 Random Password Generator

A responsive and user-friendly Random Password Generator built using HTML, CSS, and JavaScript.

## 🚀 Features

- 🔢 Custom password length (6–30 characters)
- 🔠 Uppercase letters
- 🔡 Lowercase letters
- 🔢 Numbers
- 🔣 Special symbols
- 💪 Password strength indicator
- 📋 Copy generated password
- 📜 Password history
- 🗑️ Clear password history
- 📱 Responsive design
- 🎨 Modern and clean UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📖 How to Use

1. Select your desired password length.
2. Choose the character types you want to include.
3. Click **Generate Password**.
4. Check the password strength.
5. Click the copy button to copy the password.
6. View previously generated passwords in the history section.
7. Use **Clear** to remove password history.
